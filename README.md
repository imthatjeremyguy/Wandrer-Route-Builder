# Wandrer Route Builder

Build bike loops that collect the most new [Wandrer](https://wandrer.earth) road for the fewest repeat miles.

Runs entirely in the browser on GitHub Pages. Your Wandrer KMZ export is read locally and never uploaded; road data comes from OpenStreetMap.

## Use it

1. On the Wandrer Big Map, zoom to the area you want, click Download, and choose KML/KMZ, Bike.
2. Open the site and upload the KMZ from your email.
